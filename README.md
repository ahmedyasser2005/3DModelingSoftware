# 3D Modeling Software
## CSE382 Computer Graphics, Spring 2025-2026

---

## Overview
This repository contains the professional modeling suite developed for the CSE382 Final Course Project.<br>The system focuses on the mathematical implementation of curves, surfaces, and mesh subdivision algorithms required for automotive and industrial prototyping.

## Core Features
* **Spline Engine**: Manual implementation of Bézier curves, B-Splines, and NURBS using the De Boor algorithm.
* **Surface Generation**: Real-time generation and visualization of Bézier surfaces using Bernstein basis polynomials.
* **Mesh Infrastructure**: Implementation of mesh data structures (Vertex-Face or Half-Edge) and polygon triangulation.
* **Subdivision Modeling**: Dynamic refinement using Catmull-Clark or Loop subdivision algorithms.
* **Interactive GUI**: Real-time control point manipulation and transformation visualization via a GUI-based interface.
